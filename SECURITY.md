# Security Policy

## Supported versions

Only the latest `main` branch receives security updates.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately by
opening a private security advisory on GitHub at:

https://github.com/vishnuskandha/tneb_manager/security/advisories/new

or by contacting the maintainer directly. You will receive an acknowledgement
within 5 business days and a plan for the fix.

## Scope

This is a local desktop application. Stored data (readings, databases, and CSV
backups) lives only on the machine where it runs. There are no network-facing
components, authentication endpoints, or secrets in this repository.
